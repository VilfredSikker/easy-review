Getting Started

Herdr integration

Herdr manages git worktrees and agent workspaces. The Easy Review plugin opens er inside Herdr — in a Review tab for the checked-out branch, automatically when a worktree is created, or from a Ctrl-clicked GitHub pull request URL.

Prerequisites

  • Herdr 0.7.0+ — herdr.dev
  • er on PATH — see Installation
  • git — required by er (and optionally gh for PR sync)

Install the plugin

From GitHub

herdr plugin install VilfredSikker/easy-review/tools/herdr-easy-review --yes
herdr plugin list
herdr plugin action list --plugin easy-review

plugin install clones the plugin into Herdr-managed storage and registers it globally. Use --yes to skip the interactive preview when you already trust the source.

Local development (link)

While working on the plugin in a clone of this repository:

herdr plugin link /path/to/easy-review/tools/herdr-easy-review
herdr plugin pane open --plugin easy-review --entrypoint review

What you get

FeatureHow to use it
Review tab Opens er in a Herdr tab. The pane cwd is the workspace checkout, so you review the branch checked out there. 
herdr plugin pane open --plugin easy-review --entrypoint review
Auto-open on new worktree When Herdr creates a worktree, the plugin opens a Review tab for that workspace in the background (--no-focus) so you can keep working in the main pane.
Review current branch Action easy-review.review-branch — bind it to a key (see below) or invoke from the command palette.
Review a PR link Ctrl-click (Control on all platforms, including macOS) a https://github.com/…/pull/N URL in the terminal. Herdr routes it to er --remote <url> so you can review without a local clone of that repo.

Optional keybinding

Add to ~/.config/herdr/config.toml:

[[keys.command]]
key = "prefix+r"
type = "plugin_action"
command = "easy-review.review-branch"
description = "Review branch in Easy Review"

Troubleshooting

  • “Easy Review (er) is not installed.” — Install er and ensure it is on PATH inside Herdr panes (same shell profile as your terminal).
  • Plugin not listed. — Run herdr plugin list. Re-link or reinstall if the manifest path moved.
  • PR link does nothing. — Link handlers require a modified click (Ctrl+click). Plain clicks still open the browser.
  • Logs. — herdr plugin log list --plugin easy-review
◆

Plugins run as your user and can call the full Herdr CLI. This plugin only shells out to herdr and er. Read tools/herdr-easy-review/herdr-plugin.toml and the *.sh scripts before installing from an untrusted source.
